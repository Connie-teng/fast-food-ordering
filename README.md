## ✨ 功能特色

- 🍱 **指定套餐**：A–E 五種套餐，SVG 插圖顯示，一鍵加入購物車
- 🛒 **單點商品**：11 種單品自由搭配，支援數量調整
- 🤖 **AI 套餐推薦**：輸入預算、人數、偏好，自動推薦最划算組合
- 🔥 **熱量計算機**：選餐同時即時顯示卡路里累計與健康提示
- 🌟 **今日特價**：每次開啟隨機一項商品特價
- 🎡 **幸運轉盤**：結帳前抽獎，有機會折抵現金
- 💳 **階梯折扣**：消費滿 $500 享九折、滿 $1000 享八五折
- 👤 **會員系統**：登入 / 註冊，享九五折 + 積分回饋
- 🧾 **結帳收據**：完整列出折扣明細與熱量資訊

---

## 🚀 使用方式

不需安裝任何套件，直接開啟檔案即可：

```bash
# clone 專案
git clone https://github.com/你的帳號/maidangdang.git

# 用瀏覽器開啟
open maidangdang.html
```

或直接雙擊 `maidangdang.html` 用瀏覽器開啟。

maidangdang/

- 純 HTML / CSS / JavaScript，無任何外部依賴
- 套餐插圖為 inline SVG，不需載入外部圖片
- Google Fonts：Noto Sans TC、Bebas Neue、Space Mono
